# PRISM — Bahan Canva

## Deskripsi
Platform tes penempatan dan pembelajaran Bahasa Inggris untuk mahasiswa, dengan hasil per keterampilan serta latihan vocabulary, writing, dan speaking berbantuan AI.

## Screenshot
- prism-student-dashboard.jpg — dashboard mahasiswa setelah login, sebelum menyelesaikan placement test (akun pengujian lokal).
- prism-admin-writing.jpg — pengelolaan topik writing dan rubrik penilaian AI setelah login admin (database pengujian lokal).

## Teknologi
Next.js 16, React 19, TypeScript, Tailwind CSS 4, PostgreSQL, Prisma 7, JWT, Google Gemini, BullMQ/Redis, penyimpanan kompatibel S3.
